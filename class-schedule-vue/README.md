# Class Schedule - Vue App

一个基于 **Vue 3 + TypeScript** 开发的课表 Web 应用

## 技术栈

- **Vue 3** - 前端框架
- **TypeScript** - 类型安全
- **Element Plus** - UI 组件库
- **XLSX** - Excel 文件解析
- **Day.js** - 日期处理

## 开发准备

1. 安装依赖
   ```bash
   npm install
   ```

## 开发

```bash
npm run dev
```

然后访问 http://localhost:3000

## 构建

```bash
npm run build
```

## 功能

- ✅ Excel 课表文件解析（.xls / .xlsx）
- ✅ 周次导航（上一周/下一周/回到本周）
- ✅ 日期跳转
- ✅ 课程详情列表
- ✅ 本周课程统计
- ✅ 今天高亮显示
